## Purpose

This registry tracks how each legacy PWA/APK entry point maps to the native Android replacement work. It is a living release-gate artifact, not a replacement approval.

Status vocabulary:

- `not_started`
- `in_progress`
- `implemented`
- `verified`
- `waived`
- `blocked`

Release gate vocabulary:

- `closed`: current evidence is enough for this registry row.
- `blocker`: P0 replacement release cannot pass until this row is verified or explicitly waived.
- `watch`: P1 item needs a native path, reduced version, or documented safe deferral before replacement readiness.

## Maintenance Rule

When a later task changes native behavior for a legacy entry, update that row in this registry in the same task:

1. Keep status conservative.
2. Add evidence only after automated or device verification exists.
3. Do not mark a P0 row `closed` unless status is `verified` or an explicit waiver exists.
4. Record waivers in both this registry and `.adworkflow/review_findings.json`.
