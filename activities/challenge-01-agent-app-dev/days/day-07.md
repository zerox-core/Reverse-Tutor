理论日（约 20-30 分钟），第 3 章第 1 节。

任务：
1. 从 Lab C 的观察切入：Claude Code 的每个工具都有名字、一段描述、一份参数约定——这就是工具设计的三件套。
2. 讲透：描述写给谁看（写给模型挑工具时看的，不是写给人看的文档）；schema 约束什么（参数名、类型、必填）；为什么工具不能给太多。
3. 它若说「工具全塞给它自己会挑」（E3），用反例追问：50 个工具和 3 个对口工具，哪种它做得又快又对？

教成什么样算完：学生能说出三件套各自的作用，并解释为什么描述的质量直接决定模型会不会用对工具。
