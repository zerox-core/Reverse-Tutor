# M0 四个对照实验（D1-D2 实操指南）

> 同一任务四种做法：**写一个脚本，统计一份日志文件里 ERROR 的数量**（日志可自己造 20 行，混 INFO/WARN/ERROR）。
> 核心动作是「记录」：每个 Lab 都要填观察记录表，D2 晚上要靠这些记录把「差在哪」讲给 AI 学生。

## 观察记录表（每个 Lab 填一份）

- 我手工做了哪些事（逐条列：复制代码 / 开终端 / 运行 / 读报错 / 贴回报错 / 改代码……）
- 工具替我做了哪些事
- 它做了我没让它做的事吗？哪一幕印象最深？
- 卡在哪、怎么解决的
- 大概花了多久

## Lab A：纯 LLM 基线（零安装，路径任选）

- 目标：完成一次「纯人肉循环」——AI 只出文字，执行、观察、反馈全是你亲手做。这条基线是后面所有对照实验的地基。
- 路径 A（聊天式 AI，网页或 App 均可）：DeepSeek 网页版、豆包、Kimi 等任选一个**只出文字、不替你跑**的 AI → 让它写这个脚本 → 你复制代码、保存、运行 → 报错了把报错贴回去 → 直到跑通。
  - 脚本怎么运行（Windows）：代码存成 count.py → 在文件所在文件夹按住 Shift 点右键 →「在此处打开 PowerShell」→ 输入 py count.py 回车。装不了 Python 就直接走路径 B。
- 路径 B（手动降级，连脚本都不用跑）：让 AI 生成一份 20 行混 INFO/WARN/ERROR 的日志，它逐行念、你亲手数 ERROR 个数，再让它核对——循环照样全在你手上。
- 想直接用 agent？好想法——那正是 Lab B/C/D 干的事。你可以直接跳到 Lab B，但记得回头用路径 A 或 B 补一条基线记录，否则 D2 晚上讲「差在哪」时没有对照。
- 路径不设限：上面只是三条参考走法——任何能让你亲手完成「运行 / 排错 / 拿到 ERROR 数量」的方式都行，只要最后圆回观察记录表、能跟 Lab B 形成对照就算数。
- 观察重点：**循环是你人肉完成的**——模型只出文字，执行、观察、反馈全是你。
- 降级：路径 B 就是降级的底。

## Lab B：zcode + DeepSeek API

- 前置：DeepSeek API key【实测核实点 1：注册/实名/免费额度】；zcode 获取与配置【实测核实点 2】。
- 步骤：配好 key → 同一个任务交给 zcode → 观察它怎么自己读文件、跑命令、看结果、再改。
- 观察重点：**循环是谁在完成？** 和 Lab A 比，你少做了哪些事？
- 降级：拿不到 key 或配不通 → 看演示（L2），记录表照填「演示中看到……」。

## Lab C：Claude Code

- 前置：安装与国内可达性【实测核实点 3】。
- 步骤：同一任务 → 重点看它的工具集（读文件 / 写文件 / 跑命令分别长什么样）和交互节奏。
- 观察重点：和 Lab B 比，工具更丰富了吗？它做事的「章法」差在哪？
- 降级：装不上 → 看官方演示或预录录屏（L2/L3）。

## Lab D：Codex

- 前置：安装与国内可达性【实测核实点 4】。
- 步骤：同一任务 → 对比它和 Claude Code 的交互、速度、给你的确认方式。
- 观察重点：四个 Lab 摆在一起，「agent」和「直接问 LLM」的分界线到底在哪？
- 降级：同 Lab C。

## 做完的标志

四份记录表（或降级后的两份 + 演示观察）+ 一段能脱口而出的回答：「agent 和直接问 LLM 差在哪？我亲眼看到的一幕是……」——这段话就是 D2 晚上要讲给 AI 学生的素材。
