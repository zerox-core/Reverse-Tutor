# M0 四个对照实验（D1-D2 实操指南）

> 同一任务四种做法：**写一个脚本，统计一份日志文件里 ERROR 的数量**（日志可自己造 20 行，混 INFO/WARN/ERROR）。
> 核心动作是「记录」：每个 Lab 都要填观察记录表，D2 晚上要靠这些记录把「差在哪」讲给 AI 学生。

## 观察记录表（每个 Lab 填一份）

- 我手工做了哪些事（逐条列：复制代码 / 开终端 / 运行 / 读报错 / 贴回报错 / 改代码……）
- 工具替我做了哪些事
- 它做了我没让它做的事吗？哪一幕印象最深？
- 卡在哪、怎么解决的
- 大概花了多久

## Lab A：纯 LLM 基线（DeepSeek 网页版，零安装）

- 步骤：打开 DeepSeek 网页版 → 让它写这个脚本 → 自己复制代码、保存、运行 → 报错了把报错贴回去 → 直到跑通。
- 观察重点：**循环是你人肉完成的**——模型只出文字，执行、观察、反馈全是你。
- 降级：无（这就是降级的底）。

## Lab B：zcode + DeepSeek API

- 前置：DeepSeek API key【实测核实点 1：注册/实名/免费额度】；zcode 获取与配置【实测核实点 2】。
- 步骤：配好 key → 同一个任务交给 zcode → 观察它怎么自己读文件、跑命令、看结果、再改。
- 观察重点：**循环是谁在完成？** 和 Lab A 比，你少做了哪些事？
- 降级：拿不到 key 或配不通 → 看演示（L2），记录表照填「演示中看到……」。

## Lab C：Claude Code

- 前置：安装与国内可达性【实测核实点 3】。
- 步骤：同一任务 → 重点看它的工具集（读文件 / 写文件 / 跑命令分别长什么样）和交互节奏。
- 观察重点：和 Lab B 比，工具更丰富了吗？它做事的「章法」差在哪？
- 降级：装不上 → 看官方演示或预录录屏（L2/L3）。

## Lab D：Codex

- 前置：安装与国内可达性【实测核实点 4】。
- 步骤：同一任务 → 对比它和 Claude Code 的交互、速度、给你的确认方式。
- 观察重点：四个 Lab 摆在一起，「agent」和「直接问 LLM」的分界线到底在哪？
- 降级：同 Lab C。

## 做完的标志

四份记录表（或降级后的两份 + 演示观察）+ 一段能脱口而出的回答：「agent 和直接问 LLM 差在哪？我亲眼看到的一幕是……」——这段话就是 D2 晚上要讲给 AI 学生的素材。
