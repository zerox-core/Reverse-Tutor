# D0 起点测评与环境向导（不占打卡天数）

> 意图层定义，风格无关；具体话术由角色卡配方 + 表达契约在会话中渲染（称呼克制、一步一确认、一轮最多一个问题）。

## 1. 起点测评（四条意图，逐条确认）

1. **探明操作系统**：Windows / macOS / Linux，版本不限。意图：决定后续命令与安装指引的形态。
2. **探明终端经验**：是否开过终端 / 敲过命令。意图：决定向导要不要从「怎么打开终端」讲起。
3. **探明网络环境**：能否直连外网、是否有可用镜像。意图：决定 Claude Code / Codex 走安装还是走降级。
4. **探明已有装备**：是否已有 DeepSeek API key、其他模型平台账号。意图：能复用的不重复注册。

测评结果写入会话状态，引导按分支走；用户后续透露的信息实时修正分支。

## 2. 环境向导（按分支组合）

- 共同底线：DeepSeek 网页版可用（零安装，是 L3 降级的基线）。
- L1 完整实操线：DeepSeek API key → zcode → Claude Code → Codex，每装完一个当场跑通「统计日志错误数量」任务的最小验证。
- 每步形态：AI 学生以请教方式引导，一步一确认；报错时出对照卡（报错现象 → 常见原因 → 下一步），不甩链接、不甩整段命令。

## 3. 降级链（实操深度可降，教学闭环不断）

- **L1 完整实操**：4 个 Lab 全做。
- **L2 部分实操**：≥2 个对照亲手做，其余看演示讲解。
- **L3 零安装**：网页版 DeepSeek 做基线 + 预录录屏当观察员。
- 完成判据不因档位降低：判的是「讲得清差在哪」，不是「装了几个」。

## 4. 六大劝退点预案（向导剧本预置应对意图）

| 劝退点 | 应对意图 |
|---|---|
| 注册要绑手机 | 提前告知、给预期；不接受则该工具走降级 |
| 实名认证 | 同上；强调只需一次 |
| 要充值 | 先查免费额度【实测核实点 1】；无免费额度的工具直接走降级，不让用户为活动花钱 |
| 英文页面 | 关键页面给出逐步对照说明 |
| 下载慢 | 换镜像源【实测核实点 5】；仍慢则走降级 |
| 命令报错 | 报错对照卡；连续两次同错则停手换路，不硬磨 |

运营侧：后台监控各步骤卡住率（依赖挑战运营后台，属后续迭代）。
