# 知识包 challenge-02：教 AI 学生（游戏宅）学会「吃穿住行练」健康管理

> 内容层唯一索引。机制层（会话决策 / 表达契约 / 纠错阶梯 / 掌握度闸门 / 人物融合）一律以源码为准，本包只提供源码机制可消费的内容。
> 设计依据：`docs/dev/challenge-02-build-plan.md`（v1 定稿，2026-10-06 拍板）。

## 主题与画像

- 一句话：用户用 7 天把「游戏人怎么吃、睡、坐、练、止损」完整教给 AI 学生；教会的证据进掌握度账本 = 挑战完成。
- 学生画像（拍板定稿）：**典型游戏宅**——长期久坐打游戏、凌晨睡、外卖/零食/快乐水三件套、运动量约等于零、颈肩腕已僵硬但自认「还年轻没事」、对健身有「收藏=练过」心态。
- 难度定位：中间档，面向大众的科普级；求广不求深（拍板）。
- 节奏：**碎片化、无打卡、完全自由**（拍板）；每天 15-25 分钟，断档不算失败。

## 教学评测机制：标准区间打分（本挑战核心玩法，拍板新增）

学生人设固定 → 存在一套资料支撑的「最佳实践区间」（`rubric.yaml`，五维度：睡眠/饮食/运动/久坐中断/场景针对性，各给最佳区间/可接受区间/红线/依据来源）。
流程：AI 学生主动问「老师我该怎么练/吃/睡」→ 用户（老师）给计划 → 系统按 rubric 结构化评分（LLM json mode）→ 分数 + 各维度点评进会话 → D7 汇总成绩单。**不设打卡**。

## 完成判据（草案）

每阶段至少 1 条 transfer 或 correction 的 passed 证据；D7 完成一次计划核对评测闭环（rubric 打分记录）；纯 explanation 不算完成。判据接源码 mastery 闸门，不在模板层另造。

## 资料边界（拍板）

- 凯圣王内容只取**概念科普层**（周期计划四原理/超量恢复/呼吸），不含具体训练计划；学生不主动甩计划，老师主动教或追问时才展开。
