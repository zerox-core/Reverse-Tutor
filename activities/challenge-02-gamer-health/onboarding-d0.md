# D0 起点测评与参与说明（不占天数）

> 意图层定义，风格无关；具体话术由角色卡配方 + 表达契约在会话中渲染（称呼克制、一步一确认、一轮最多一个问题）。

## 1. 起点测评（四条意图，逐条确认）

1. **探明游戏习惯**：主玩什么、每天大约几小时、一般玩到几点。意图：让学生人设的处境与老师同频，D1 健康账本有真实素材。
2. **探明身体现状**：颈/肩/腕/腰有没有已经能感觉到的不适，频率如何。意图：决定 D3 急救包的侧重点（颈 vs 腕 vs 腰）。
3. **探明饮食现状**：外卖频率、含糖饮料、熬夜晚餐/夜宵习惯。意图：D4 用老师/学生共同熟悉的真实场景做挑错练习。
4. **探明运动现状**：最近一个月有没有任何形式的动；住家还是宿舍、有没有楼道/小区可走动空间。意图：D6 和 rubric 的「场景针对性」维度以这个为基准。

测评结果写入会话状态，后续每天的内容按分支侧重；用户后续透露的信息实时修正分支。

## 2. 参与方式说明（拍板原则，开场即讲清）

- **无打卡、无催收**：本挑战不按天签到，断档不算失败；完全碎片化，哪天有空哪天教。
- **每天 15-25 分钟**：D1-D6 是教学日，D7 是综合验收（计划核对评测）。
- **老师是产出方**：AI 学生只负责提问、复述、犯错和被纠正；计划和方案永远由老师产出，系统按 rubric.yaml 的「最佳实践区间」给老师的计划打分。
- **资料可追溯**：学生引用的知识点来自权威资料库（膳食指南/体育总局/队医科普等），可按需展示出处。

## 3. 降级与弹性

- 时间少：每天任务可拆两次完成，判据不变（判「讲得清」，不判「坐了多久」）。
- 某天内容已会：可直接请学生复述要点跳级核验，通过即进入下一天。
- 学生提前要计划：任何一天都允许触发 rubric 评测（不必等 D7），D7 仍要求完整闭环一次。

## 4. 劝退点预案

| 劝退点 | 应对意图 |
|---|---|
| 「健康知识我早就懂」 | 请他先给学生讲一遍 D1 账本——讲得清才算懂，讲不清正好开始 |
| 「我没时间系统健身」 | 强调本挑战核心就是碎片化和零门槛，计划评分里「场景针对性」专治不接地气 |
| 「我身体没毛病」 | 用 EDG 调研（几乎 100% 选手曲度消失）说明劳损静默积累，请他从 D2 坐姿自查开始 |
| 「打分会不会很虚」 | 亮 rubric.yaml 的五维度区间与资料出处，分数逐维度可追问 |
