# 注册营养师水平评价考试：四大模块框架

考试形式：单项选择题 200 题，满分 100 分，机考 180 分钟。实践技能部分原则上不少于 60%-70%。

## 模块一 食物与营养（20%）

1. 基础营养：营养相关基本概念；蛋白质；脂肪；碳水化合物；能量；矿物质；维生素；水与其他膳食成分。
2. 食物营养：食物的营养学评价；食物的化学成分；各类常见食物及营养特点；营养强化食品；营养素补充剂；保健食品。
3. 食品科学基础：食品分析方法；食品加工与营养。
4. 食品卫生：食品污染及其预防；食品添加剂及其管理；各类食品卫生及其管理；食源性疾病及其预防；食品安全风险评估与监督管理。

## 模块二 个体和群体营养管理（40%，占比最大）

1. 医学基础：人体解剖学、生物化学、生理学、微生物学、免疫学。
2. 营养评估及干预：营养评估、营养诊断、营养干预。
3. 不同人群营养：孕妇、乳母、婴幼儿、学龄前儿童、学龄儿童、老年人、素食人群；高温/低温/高原/特种作业等特殊作业人群；运动营养。
4. 疾病营养：住院患者营养风险筛查与评估；医院膳食；肠内/肠外营养支持；代谢性疾病、心脑血管疾病、泌尿系统疾病、消化系统疾病等的膳食和营养治疗（MNT 基础）。

## 模块三 公共营养和营养教育（20%）

1. 膳食指南及 DRIs：中国居民膳食指南；中国居民膳食营养素参考摄入量。
2. 标准政策法规：营养与食品安全法规、政策、食品安全国家标准。
3. 营养调查与监测。
4. 社区营养和慢病管理：家庭平衡膳食；营养不良的膳食管理；慢性病的膳食管理；体重控制；运动和健身。
5. 营养教育与咨询：营养教育；营养咨询；饮食行为。
6. 环境与健康：环境与健康导论；流行病学与卫生统计学基础。

## 模块四 餐饮管理（20%）

1. 膳食设计和管理：食物原料；采购验收；餐饮成本控制；团体膳食菜单设计；进餐环境设计。
2. 食谱编制：营养配餐；食谱编制方法；不同人群的食谱编制及评价；合理膳食制度。
3. 膳食制备：烹调方法；烹饪与食物营养；饮食文化。
4. 餐饮卫生和管理。

# DRIs（中国居民膳食营养素参考摄入量）指标体系

DRIs 由中国营养学会组织编写，2023 版为最新版（2000 首版、2013、2023 两次修订），包含必需营养素 35 种、水与膳食纤维等其他膳食成分 16 种，共约 1300 多个数值，覆盖婴儿到成人、孕妇乳母等不同人群。核心指标：

- EAR（平均需要量）：衡量个体摄入不足风险、评估群体摄入不足发生率。
- RNI（推荐摄入量）：个体每日摄入目标值，制定食谱时常用。
- AI（适宜摄入量）：缺乏足够证据制定 RNI 时的参考目标。
- UL（可耐受最高摄入量）：安全上限；服用营养素补充剂者尤其要保证总量低于 UL。
- AMDR（宏量营养素可接受范围）：针对碳水化合物、蛋白质、脂肪及脂肪酸，用于降低超重肥胖、血脂异常、糖尿病、心血管疾病风险。
- PI-NCD（预防慢性病的建议摄入量）：如钾、钠、维生素 C。
- SPL（特定建议值）：针对植物化学物等其他膳食成分（如大豆异黄酮、叶黄素、番茄红素、植物甾醇等）。

# 与「游戏人群健康 7 天挑战」的映射

- D4 吃：模块一（基础营养、食物营养）+ 模块三（膳食指南及 DRIs、体重控制）是直接依据；本知识包的 src-06（膳食指南八准则）即模块三的核心科普产出。
- D1/D2/D6 练与久坐：模块三「运动和健身」「体重控制」提供框架背书；具体方案走 src-01~05 体育总局科普。
- D5 睡：考纲不直接覆盖睡眠，属运动健康生活方式交叉域，本包以 src-07/src-09 补充。
- 教学边界：挑战活动只用到「公共营养 + 基础营养」的科普层；模块二的医学基础与疾病营养（MNT）属于专业诊疗范畴，AI 学生与老师都不得越界给医疗建议。
