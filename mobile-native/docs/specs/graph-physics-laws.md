## 第一定律：节点力学（以黑曜石 Obsidian 知识图谱为参照）

1. **布局引力只来自连线（边）**：相连节点之间是弹簧引力（胡克力，理想连长 springIdeal + 轴向阻尼 springDamping）。
2. **黑洞引力 = 开普勒公转引力（R87）**：黑洞对节点有真实向心引力 F=GM/d²，节点出生自带圆轨道速度 v=√(GM/d)，引力恰好充当向心力——节点不坠不飞、稳定公转。**该引力量级远小于布局力（约 1/4000），只弯曲轨迹、不参与布局、不得把节点吸向中心**；节点少时照样不成环（一个地球还是一个地球，圆的只是轨迹，第四定律不破）。
3. **斥力来自节点自身**：每个节点自带斥力场，与距离平方成反比（repulsion / d²），与是否相连无关。
4. **节点是实体，不可重叠**：任意两节点存在碰撞体（两节点半径之和 + collisionPadding），进入即推挤分离。任何布局、动画、拖拽、入场都不得产生节点重叠。
5. **连接与运动遵循真实力学**：速度阻尼（径向强、切向零，保住公转）、速度钳制、弹簧收敛、惯性滑停后回归力场——禁止用脚本化位移、瞬时摆位伪造「物理感」。

## 第二定律：三区域模型

以黑洞核心半径为 1 单位，从里到外三个区域：

1. **核心区（黑洞本体）**：节点接触核心 = 判定遗忘，播放消失动画。（未实现，当前不做。）
2. **遗忘区 / 缓冲区**（核心边缘 → 6 倍单位，R82 拍板的半径）：与遗忘算法联动的过渡区，判定逻辑由后端遗忘曲线驱动。（后端任务，当前不做。）
3. **节点活动区**（遗忘区以外）：所有节点的默认出生位置与正常工作区域。

## 第三定律：当前工作范围 = 仅节点活动区

- 一切迭代只在节点活动区内进行；**不做缓冲区、不做遗忘本身**（遗忘曲线的具体函数与数值是后端任务）。
- **遗忘的力学表达 = 轨道衰减（R87 拍板，已落地为引擎机制框架）**：遗忘值升高 → 切向速度目标按 (1-forget) 抽走（刹车）→ 引力占优、轨道自然内旋：活动区 → 遗忘区 → 坠入核心。**连续、渐进、绝无到点瞬移**。衰减节点全程不脱离力场（受力也施力、不与邻居打架重合）。点按/拖回抢救 = 重新注入圆轨道速度 + 遗忘清零 + 冷却重置，可逆。
- **遗忘区屏障 = 随遗忘渗透（R87 修订，在役）**：对**健康节点**（保护期内或遗忘未过门 forget<0.5）是硬边界——边界推力（exclusionPush）+ 积分位置钳制，进不来、连线不会「接进」黑洞；对**衰减节点**（forget≥0.5）渗透——不再外推、不再钳制，由轨道衰减自然穿入。该屏障数值（门限 0.5 等）为占位，等后端遗忘曲线到位后统一对接。
- 已实现的呼吸警告 / 点击抢救机制保持现状、不扩展。

## 第四定律：环形是自然涌现，不是目标

1. **圆感只来自四个来源**：直线边、力学平铺、公转轨迹、节点数量。节点足够多且足够离散时，直线连接 + 力学会自然把节点平铺到黑洞一圈——那是结果，不是目标。
2. **禁止为成环而**：
   - 弯折连线（R85 拍板：关系线永远是直线；**R87 补充：直线几何不动，线段在遗忘区内的部分按渐隐遮断渲染——几何不弯、视觉不穿越**）；
   - 把节点塞进遗忘区 / 缓冲区（衰减节点经轨道衰减自然进入除外）；
   - 让节点重叠、挤压堆叠；
   - 脚本化摆位、强制成环。
3. **星系视角**：黑洞没有八大行星、只有一个地球时，一个地球怎么也不会分成一个圆——圆的只是它的**轨迹**。节点与黑洞同理：公转轨迹是圆环，节点分布不必是。
4. **局部集中公转是物理正确**：关联性越强、越基于同一母节点的节点群，只会集中在一片区域绕母节点公转（R83 层级轨道），反而越难成环——这不是缺陷，是力学的必然结果。只有离散节点变多、向四周发散后，环才会自然出现。
