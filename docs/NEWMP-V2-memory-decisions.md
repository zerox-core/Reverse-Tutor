# NEWMP-V2 窗口记忆设计决策记录

> 2026-09-17 与用户在任务 7686431518440295694 评论串中逐条拍板。本文件是该轮设计讨论的唯一权威记录，后续契约与接线以此为准。

## 锁定的决策

1. **两层记忆架构**：学习窗口的本地记忆（窗口内分层）+ 全局分身智能体的投影式全局记忆。分身读取其他窗口 = 信息注入问题：只消费各窗口回流到共享投影层的结构化事实，不扒原文、不碰私域。
2. **窗口记忆四层**：
   - 第 0 层 原始轮次：滑动窗口定长保留原文（细节保真）+ 滑出批次递归摘要；
   - 第 1 层 观测：类别/值/来源类别/置信度/时间/来源句柄六变量，每批 0~3 条，不逐句提取；
   - 第 2 层 模式：同类观测聚类（次数/时段分布/首尾时间），不存原文；
   - 第 3 层 窗口级生效值：槽位制当前认知，唯一有资格回流全局投影的内容。
3. **滑动窗口默认值**：token 预算 6000 + 条数保险 60（业界均值量级），先默认值上线，agent 后续出 token 用量统计，用户再人工调整。
4. **递归摘要层开启**。理由（用户原话要义）：教学软件里用户某次粗心、AI 某次提问是教学关键，细节必须留。
5. **提取器规则先行，云端后置（BYOK）**：早期本地规则提取器为主，零平台侧模型成本；后期用户配置 API key → 重启按钮生效 → 扫描 key 下可用模型列表 → 选 flash 档便宜模型做摘要/提取侧。营收允许后再评估内置模型。
6. **权重机制**：显著性（深夜 23:00-06:00 时段规则表）× 来源强度（用户自述 > 行为观察 > 模型猜测）× 重复与反馈。REMINDER_FEEDBACK（用户对提醒的回应）为一等公民、恒高权重；权重算多少是确定性的，权重挂在哪个类别允许语义参与（LLM 提议、代码裁决）。
7. **窗口拓扑（fork/merge/snapshot/心跳）**：契约已冻结在 core:domain（WindowTopologyContracts / WindowTopologyPolicy），V2 不接线，后续单独设计。
8. **全局行为信号**（聊天时段、设目标频率、挑战参与等交互日志）：契约后置，随窗口记忆结构成熟再定。
9. **提取时机**：消息滑出窗口时批量提取，异步后台执行，绝不阻塞聊天回路（对齐 Mem0 异步提取设计，其公开数据 p95 延迟降 91%，全量上下文对照组 26K tokens/query、p95 17s 不可用于生产）。

## 参考架构（2026-09-17 调研）

- **MemGPT / Letta**（arXiv:2310.08560）：FIFO 会话队列 + flush 阈值 + 滑出递归摘要；core/archival/recall 三层；token 阈值触发而非条数。
- **Mem0**：extract → consolidate（ADD/UPDATE/DELETE/NOOP）→ retrieve；异步提取。
- **Zep / Graphiti**：时序知识图谱，记录事实的生效时段。
- **SillyTavern World Info (lorebook)**：关键词触发的结构化条目选择性注入 + token 预算封顶，与「分区存储 + 选择性投影」同构。
