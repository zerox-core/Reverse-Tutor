# 素材驱动阶段生成器（Material-Driven Stage Generator）设计稿草稿

> 2026-09-29 立项，从《大阶段进度模型》§11 环节①拆出单开。
> 关联：主模型 docs/specs/stage-progress-model.md（粗分类即其 Stage[] 数据模型）。
> 状态：草稿 v0.1，待朱曦策拍板。

## 1. 定位

会话创建时把「素材」转成「粗分类阶段划分」（Stage[]），定框架、上面板。

边界：细分类不在本设计稿范围（会话内增量发现，见主模型 §11.5）。

## 2. 双源链路

### 2.1 有书资料：书目录解析

- 输入：教材目录 / 章节结构 / 教学大纲（syllabus）；
- 解析：目录 → 章节树 → 按 stage_goal 成对结构（单数日「学生能说清」+ 双数日「出题验证+纠错闭环」）切阶段；
- 校验：章节覆盖完整性（目录不跳章、不重叠）；
- 产物：Stage[]，全部标「有据」。

### 2.2 无书资料：LLM 自拆 + 检索校验（四步）

1. **LLM 自拆草稿**：按主题拆阶段草案（Stage[] + 各阶段目标）；
2. **证据检索校验**：拿教材目录 / syllabus / 公认学习路径（如先椭圆后双曲线类顺序约定）检索比对，逐阶段对齐或修正；
3. **置信标注**：每阶段标证据等级——**有据**（≥2 个独立来源支撑顺序与内容）/**推断**（仅 LLM 自拆或单源）；全流程不掩盖推断等级；
4. **人审定稿**：用户过目后定稿；有据阶段默认过，推断阶段高亮提醒确认。

## 3. 冷门主题降级链

- 检索不到公认路径 → 默认**线性拆解**（基础→进阶→综合）+ 全阶段标「推断」+ 强提醒用户定稿确认；
- 原则：宁可明确说「这是推断」，不假装有据。

## 4. challenge-01 的角色：人工精编基准

challenge-01 六阶段（S1-S6，17 天，见主模型 §4）是人工精编的阶段划分，作为生成器的抽检基准：生成器产出的划分与其结构（成对验收、证据可判定、阶段数量级别合理）一致才算合格。

## 5. 修正原则

学习中修正阶段边界时，**先动推断级阶段**；有据级阶段的修正需要新证据。
