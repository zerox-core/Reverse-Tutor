## 0. 定位：图谱是投影层，不决定记忆算法

产品记忆机制分两大类：

1. **RAG 知识库检索**——知识的存储与召回；
2. **图量线性关系记录**——用户学习历程中主题之间的关系与演进，本图谱负责表达这一类。

黑洞知识图谱（feature/memory 的 BlackHoleGraphEngine / BlackHoleGraphScreen）**不是记忆算法的决策者，而是核心记忆设计投影到用户层的那块屏幕**。算法在记忆层（core:domain / core:data / v2 后端），图谱只做表达：它有自己的布局、动效、LOD 等显示算法，但节点的生死、权重的增减，全部由记忆层的数据驱动。

## D1. 双层结构：知识点为骨，事件为血肉

图谱节点单位采用**双层结构**，不是纯知识点图、也不是纯事件图：

- **骨架层（用户看到的图）**：节点 = 学习主题（知识点，如「高中数学」「集合」），边 = 「属于 / 细化」的父子层级。
- **记录层（节点内部）**：每次涉及该主题的实质性教学 = 一条**事件**，挂在节点的子页面（事件时间线），点开节点可看事件预览、跳回源会话。

事件类型四分：**讲解 / 问答 / 复盘 / 测验**。

## D2. 数据模型草案

```
Node(id, title, parentId, type, createdAt)
Event(id, nodeId, sessionId, type, timestamp, summary, effectiveness)
```

- `Node.strength` **不落库手存**，由该节点事件流的遗忘曲线加权计算得出（涌现值）。
- `Event.effectiveness` 对接 mastery-evidence-weighting 的证据闸门模型：
  explanation=0.35 / retrieval=0.55 / transfer=0.72 / delayed_retrieval=0.82 / correction=0.90，
  仅 passed / partial（×0.75）涨分，failed 回退 0.08，alpha=0.35 EMA，0–1 归一。
- 每条事件必须带效果分才允许入库——没评分的事件是遗忘曲线的脏数据。

## D3. 真节点创建门槛（用户 2026-09-19 拍板）

1. **建节点**：用户首次**实质性**展开某主题才建——该主题下发生 **≥3 轮实质讲解 / 问答**，或用户以「我要学 X」显式开启会话。闲聊中「提了一嘴」不进图。
2. **归并**：新讨论先语义匹配已有节点（别名表 + embedding 相似度），匹配上 → 只追加事件、不建节点；匹配不上 → 新建。
3. **建分支**：新主题与已有节点存在「属于 / 细化」关系时挂为子节点（高中数学 → 集合）；并列主题挂同级。层级只认这一种边。

## D4. 卫星机制：活跃事件的投影

- 节点子页面是事件的**主存储**；图谱上把**活跃事件**以「卫星小点」形式挂在宿主节点周围（如讲完「集合的交并补」，「集合」旁长出一颗卫星）。
- 卫星带**主题指纹**（语义签名），关联源会话；点开可跳回那条会话记录，包括后续的代码动画演示（如圆锥切割）。
- 卫星生命周期：**诞生 → 冷却变暗变小 → 收回宿主子页面**。数据永存，视觉退场——一次性信息体面退出，不删、不占图。
- 卫星只显示最近活跃的几条，防止事件级节点把图撑爆。

## D5. 卫星晋升机制（用户 2026-09-19 拍板）

卫星是节点的「试用期」。同主题卫星追问加深，三条阈值**同时满足**即晋升合并为节点：

1. 同话题卫星 **≥3 条**（语义聚类判定同一话题）；
2. **跨 ≥2 天 / ≥2 个会话**（分布式重复，防一次长聊刷出节点）；
3. 累计 **≥6 轮实质问答**（确认讨论深度）。

晋升动作：

- 卫星合并成新节点；**卫星不消失，转化为新节点的初始事件流**（子页面自带完整历史：哪天问了什么、动画链接都在）。
- 权重 = 各卫星权重带时间衰减求和；保护期按节点规则重新计算——权重增强是用户行为挣来的。

## D6. 横向拓展节点的挂载（用户 2026-09-19 拍板）

横向拓展（好奇追问：椭圆 → 圆锥曲线 → 解析几何的「解析」→ 欧拉 → 数学史）是一等公民的学习行为，AI 只引导、不拦截、不强制拉回学习目标。

- 横向拓展诞生的节点**不进父子树**，用**横向弱连线**挂在诞生它的主题旁（数学史 ⟷ 解析几何），视觉为细线，不抢层级关系——硬挂进课程层级会污染骨架。
- 后续用户开始**系统性学习**该主题（符合 D3 建节点标准且明确属于某层级）时，升格进树、成为正式分支。

## D7. 遗忘三阶段：断链离散（用户 2026-09-19 确认）

遗忘作用于**事件层**；节点记忆的衰退是事件集体遗忘的涌现。小节点 / 卫星的遗忘过程：

1. **冷却保护期**：连边正常、参与力场布局、遗忘冻结；
2. **断链离散期**：遗忘进度越线 → **剪断与母节点的边**，节点脱离弹簧力场（不牵连母节点与兄弟节点），独自沿漩涡漂向黑洞、进入闪烁呼吸；
3. **坠入核心**：真正被遗忘，从投影层消失。数据层事件记录仍在（子页面标灰「已遗忘」），**非物理删除**。

**点击抢救**：用户点击闪烁节点 → 进入复习流程 → 完成后节点回归原位、边重建、冷却期重置（= 间隔重复的「复习重置遗忘曲线」）。复习完成本身生成一条 delayed_retrieval / correction 强证据，回喂 mastery 模型——抢救不只是视觉回归，还真实涨掌握度。

对应现有实现：BlackHoleGraphEngine 的 Dying 模式已按此机制工作（脱离力场、不拖邻居），protectionSeconds=90f / forgettingFullSeconds=240f / decayOrbitBoost=1.6f / decayRadiusPow=0.8f / absorbForgetGate=0.85f 为占位参数，待真实遗忘曲线算法替换。

## D8. 骨架豁免规则（用户 2026-09-19 拍板）

用户遗忘的是细节，不是框架（「高中数学」几乎不会被忘掉，忘掉的是例题与性质细节）。规则：

- **骨架节点事实豁免黑洞，保护期 ∞**；只有枝叶细节与事件会坠洞。
- 骨架判定 = f(层级深度, 出度, 证据强度)：深度越浅、子节点越多、强证据（correction / delayed_retrieval）越多 → 越接近骨架。
- 即黑洞的「食谱」天然是枝叶，主干不在菜单上——黑洞周边永远只有零星濒忘小点，从机制上杜绝臃肿。

## D9. 权重模型

- **节点强度** = 其事件流遗忘曲线的加权和（涌现，不手存）；事件权重随时间按遗忘曲线衰减。
- **卫星权重** = 单条事件强度 × 时间衰减；晋升时求和继承给新节点。
- **降级对称**：晋升节点长期不再触碰 → 事件流照常走 D7 断链流程 → 节点可降回卫星、再坠入黑洞。信息 → 卫星 → 节点 → 卫星 → 黑洞，每个方向都有路，全部听数据指挥。

## D10. LOD 信息配给（密度与美感的权衡）

臃肿的根因不是信息多，是所有信息同级同时显示。投影层按三维度配给：

1. **按缩放级别**：缩小看全局 = 只显示骨架（母节点 + 中层，数量预算封顶）；放大进入区域 = 子节点、卫星事件点才展开（地图式 LOD）。
2. **按记忆状态**：衰减中的细节本身在变暗变小走向黑洞——信息减少是遗忘动画的天然副产品。
3. **按聚合**：同一母节点下健康子节点超过预算（初始值 8，可调）收成一团「星云」，显示「+N 个主题」，点开或放大才散开。

原则：骨架常显、细节按需、黑洞边只留濒忘者。

## 接口对齐

- **core:domain**：MemoryObservation（六变量白名单、禁存原文）、CompanionMemoryRepository、LearningLedgerRepository（append-only 台账）、GraphRepository（已存在、待接线）。
- **v2 后端**：kg_extractor.py（每轮抽取 concept 节点 + 边类型：学习中 / 已掌握 / 容易混淆 / 曾误解 / 前置于 / 常用于 / 偏好 / 错在）、kg_gate.py（隐私门：存学习证据不存生活细节）、upsert_mastery（证据闸门，见 D2）。
- 图谱读取的节点 / 边 / 强度，全部来自上述记忆层；图谱不回写算法状态，只回写「用户交互事件」（点击抢救完成 = 一条复习证据事件）。
