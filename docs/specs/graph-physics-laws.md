# 黑洞知识图谱 · 物理定律（严格执行，不可推翻）

> 2026-09-20 用户拍板。本文件是黑洞知识图谱的**最高物理约束**：后续任何迭代（任何窗口、任何任务轮）都不得推翻、绕开或「为了效果」临时违反这些定律。与本文冲突的实现一律改实现，不改定律。工作范围见第三定律。

## 第一定律：节点力学（以黑曜石 Obsidian 知识图谱为参照）

1. **引力只来自连线（边）**：相连节点之间是弹簧引力（胡克力，理想连长 springIdeal + 轴向阻尼 springDamping）。**黑洞本身对节点没有任何引力**（R65 已删除 holeGravity 及一切向心漂移，禁止以任何形式复活）。
2. **斥力来自节点自身**：每个节点自带斥力场，与距离平方成反比（repulsion / d²），与是否相连无关。
3. **节点是实体，不可重叠**：任意两节点存在碰撞体（两节点半径之和 + collisionPadding），进入即推挤分离。任何布局、动画、拖拽、入场都不得产生节点重叠。
4. **连接与运动遵循真实力学**：速度阻尼、速度钳制、弹簧收敛、惯性滑停后回归力场——禁止用脚本化位移、瞬时摆位伪造「物理感」。

## 第二定律：三区域模型

以黑洞核心半径为 1 单位，从里到外三个区域：

1. **核心区（黑洞本体）**：节点接触核心 = 判定遗忘，播放消失动画。（未实现，当前不做。）
2. **遗忘区 / 缓冲区**（核心边缘 → 6 倍单位，R82 拍板的半径）：与遗忘算法联动的过渡区，判定逻辑由后端遗忘曲线驱动。（后端任务，当前不做。）
3. **节点活动区**（遗忘区以外）：所有节点的默认出生位置与正常工作区域。

## 第三定律：当前工作范围 = 仅节点活动区

- 一切迭代只在节点活动区内进行；**不做缓冲区、不做遗忘本身**。
- 已实现的 Dying 漩涡 / 呼吸警告 / 点击抢救机制保持现状、不扩展，等后端遗忘曲线到位后统一对接。
- **遗忘区屏障（短期方案，已生效）**：遗忘区边界是硬边界——边界推力（exclusionPush）+ 积分位置钳制，任何自由节点都进不来，连线永远不会「接进」黑洞。该屏障是遗忘算法落地前的临时形态，届时由算法接管区域判定。

## 第四定律：环形是自然涌现，不是目标

1. **圆感只来自四个来源**：直线边、力学平铺、公转轨迹、节点数量。节点足够多且足够离散时，直线连接 + 力学会自然把节点平铺到黑洞一圈——那是结果，不是目标。
2. **禁止为成环而**：
   - 弯折连线（R85 拍板：关系线永远是直线）；
   - 把节点塞进遗忘区 / 缓冲区；
   - 让节点重叠、挤压堆叠；
   - 脚本化摆位、强制成环。
3. **星系视角**：黑洞没有八大行星、只有一个地球时，一个地球怎么也不会分成一个圆——圆的只是它的**轨迹**。节点与黑洞同理：公转轨迹是圆环，节点分布不必是。
4. **局部集中公转是物理正确**：关联性越强、越基于同一母节点的节点群，只会集中在一片区域绕母节点公转（R83 层级轨道），反而越难成环——这不是缺陷，是力学的必然结果。只有离散节点变多、向四周发散后，环才会自然出现。
