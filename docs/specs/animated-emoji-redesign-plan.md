## 路径一：Blender 平面效果手绘动画（可做）

- 本机有 Blender（F:\blender_db），我可经 MCP 用 bpy 脚本驱动：Grease Pencil 平面逐帧 / 2D 骨骼形变，导出 PNG/WebP 帧序列或 Lottie 后接入 App。
- **能做的**：程序化平面动效（摇摆、弹跳、形变、表情切换）、统一风格的帧序列批量产出。
- **诚实边界**：代码驱动的「手绘感」有上限——真正手绘的灵气需要人工 art direction 多轮打磨；适合先出机械精准的底版，再由人修。
- 工作量：单表情约 0.5~1 天（含接入），全套看表情数量。

## 路径二：生视频模型 + 抠图去水印（部分可做）

- **生视频这一步我做不了**：我当前没有可直接调用的内置生视频模型（只有图片生成 Seedream、视频理解）。需用户侧用即梦/豆包/可灵等生成。
- **后期处理我能做**：视频抠图只留表情区域 + 去水印
  - 流程：ffmpeg 抽帧 → 抠像（rembg 或 RVM）→ 表情区域自动裁剪 → 固定位置水印遮罩/修复 → 透明背景 WebP 帧序列。
  - 算力：在用户 Windows 本机 Python 跑（RVM 需 torch；rembg 较轻）。
  - 水印若是平台固定角标（多数生视频平台如此），遮罩修复效果稳定；满屏动态水印则不在能力范围。
- 工作量：管线搭好约 1 天，之后每条约几分钟批处理。

## 建议顺序（动工时）

1. 先定全套表情清单与风格基准（几张关键帧人工定调）；
2. 路径一出底版，路径二补特殊动作；
3. 统一输出透明 WebP 帧序列，替换 drawable 并评估包体积。
