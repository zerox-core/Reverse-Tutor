# 问题哲学 ➔ 通用认知工具 抽象清单

> 这一份和「教育学」那份的分工：
> - 教育学给的是**「怎么教」**——指导强度、记忆、反馈、阶段。
> - 问题哲学给的是**「什么算一个真问题、什么算一个假回答」**——追问的合法性与边界。
>
> 后者恰好是反转家教最缺的东西：AI 学生会追问，但追问得**对不对、有没有资格问**，没有判据。

---

## A 组 · 意义与语言的边界

### A1. Wittgenstein《哲学研究》(1953)

- **方法论**：
  - **语言游戏**：词的意义不在指称，而在它被使用的那套规则里。
  - **家族相似**：很多概念没有共同本质，只有交叉重叠的相似网络。
  - **私人语言论证**：不能被公共检验的东西，不能被称作「知道」。
  - **遵守规则的悖论**：规则不能自己决定自己的应用，需要训练与共同体。
- **治的失败**：用户说了个词，AI 学生假装懂；或反之，AI 学生要求一个「精确到本质」的定义，而那个概念本来就只有家族相似。
  - 这是**教学里极高发的误伤**：逼学生给出一个根本不存在的精确定义。
- **抽象工具**：
  - `probe_usage_not_essence`（问用法而非问本质）
    - 治的失败：把「请给出精确定义」当作万能追问，结果逼出伪问题
    - 出参：三种更合法的追问角度——这个词在什么场合用、它跟相邻词怎么区分、用错了会出什么后果
  - `check_private_criterion`（私人判据检验）
    - 治的失败：结论只对说话者自己成立，无法被第三方验证
    - 出参：这个说法是否只剩「我感觉」，能否改写成可公共检验的形式

### A2. Austin《How to Do Things with Words》(1962)

- **方法论**：话语不只是描述世界，它**做事**。三分：语谓（说了什么）、语旨（说话时在做什么）、语效（说后产生了什么效果）。**恰当性条件**（felicity conditions）：一个行为要成立，需要满足前置条件。
- **治的失败**：用户说「这就证明了」，但「证明」这个言语行为的恰当性条件（前提、推理、结论）根本没满足。这是**用言语行为假装完成了一个动作**。
- **抽象工具**：
  - `check_speech_act_felicity`（言语行为恰当性检验）
    - 入参：用户的表述（如「我证明了 X」「我总结一下」「这一步显然成立」）
    - 出参：他声称在做的动作、该动作的恰当性条件清单、**哪条条件未被满足**
    - **这是抓「假装完成」的通用利器**：「显然」「容易看出」「同理」都是恰当性条件缺失的高发词。

### A3. Grice《逻辑与会话》(1975)

- **方法论**：合作原则 + 四准则（量：该多则多该少则少；质：不说假话不说无据的话；关系：切题；方式：清楚不含糊）。**故意违反**某准则会产生**会话含义**。
- **治的失败**：用户回答绕圈子、堆料、跑题。这些都不是「答得不好」，而是**违反了某条具体的准则**——可以精确命名。
- **抽象工具**：
  - `detect_maxim_violation`（会话准则违背定位）
    - 入参：问题 + 回答
    - 出参：违反了哪条准则（量/质/关系/方式）、是故意还是无意、若是故意则推出什么含义
    - 价值：把「你答得不好」这种无用评价，变成「你违反了量的准则：我问的是原因，你给的是背景」这种可执行反馈

## B 组 · 知识如何增长与如何崩塌

### B4. Popper《猜想与反驳》(1963)

- **方法论**：科学不是证实而是**证伪**。可证伪性是划界标准。理论不能被孤立检验（Duhem-Quine 整体论），检验总是连带一堆辅助假设。
- **治的失败**：用户给出一个「怎么都能解释」的说法——这恰恰是最没信息量的。
- **抽象工具**：
  - `demand_falsifier`（证伪条件索取）
    - 入参：用户的主张
    - 出参：什么观察结果会推翻它；若答「没有」，则该主张不可证伪，标记为信息量为零
    - **教学价值极高**：当用户说出「反正它总是对的」，这个工具能把他逼到墙角
  - `locate_auxiliary_hypothesis`（辅助假设定位）
    - 治的失败：反例出现时，学习者通过无限制地修补辅助假设来保住主理论（这是退化的）

### B5. Kuhn《科学革命的结构》(1962)

- **方法论**：常规科学（在范式内解谜）→ 反常（anomaly）→ 危机 → 范式转换。反常不是错误，是范式边界的信号。
- **治的失败**：把「反常在增多」误判为「我学得不好」，或反过来，把范式边界当成永恒真理。
- **抽象工具**：
  - `classify_anomaly_status`（反常状态分级）
    - 入参：当前理论框架、已出现的反常
    - 出参：这是待解谜题（范式内可解）、累积反常（范式承压）、还是范式失效信号
    - 教学价值：帮学习者区分「再想想」和「这套框架根本装不下这件事」

### B6. Lakatos《科学研究纲领方法论》(1978)

- **方法论**：研究纲领有**硬核**（不可放弃）与**保护带**（可调整）。纲领分**进步性**（能预言新事实）与**退化性**（只做事后修补）。
- **抽象工具**：`distinguish_hardcore_protective_belt`（硬核与保护带分离）——判定学习者刚刚放弃/修改的东西，是硬核（该放弃整个框架）还是保护带（正常调整）。

## C 组 · 提问的伦理与技术

### C7. 苏格拉底诘问法（柏拉图早期对话）

- **方法论**：elenchus——先接受对方主张 p，再通过追问推出与 p 矛盾的结论，最后进入 **aporia**（困惑状态）。关键在：**困惑不是失败，是转向的前提**。
- **治的失败**：AI 学生为了显得聪明，一口气推翻了对方，把对话终结在对方的尴尬里。**aporia 之后必须给出路**，否则是纯粹的羞辱。
- **抽象工具**：
  - `construct_elenchus`（诘问链构造）
    - 入参：用户主张 p、他同时接受的其它信念
    - 出参：能推出矛盾的最小追问序列
  - `manage_aporia_landing`（困惑着陆管理）
    - 治的失败：把人问到哑口无言后不管了
    - 出参：本次困惑后必须提供的三样东西——矛盾点定位、矛盾为什么会出现的解释、下一步最小可行动作

### C8. 柯林武德《历史的观念》(1943)

- **方法论**：一切历史都是**对问题的回答**。要理解一个命题，必须还原它在回答什么问题。脱离问题的答案无法被评价。
- **治的失败**：用户背了一堆结论，但已经丢失了这些结论当初在解决什么困境。这是「背了但不会用」的根本原因。
- **抽象工具**：
  - `reconstruct_original_question`（原始问题还原）
    - 入参：用户陈述的结论/公式/定理
    - 出参：它当初是为了解决什么问题而出现的；如果不用它，会出什么麻烦
    - **这是解决「知道公式但不知道为啥有公式」的通用算子**

### C9. 加达默尔《真理与方法》(1960)

- **方法论**：理解是**视域融合**。解释者带着自己的前见，与被解释者的视域交融。前见不是偏见，是理解的前提。**视域不交融时，理解就是假象**。
- **治的失败**：用户用自己熟悉的框架强行解释一个不属于该框架的东西（用初中的函数思维解释拓扑概念），然后以为懂了。
- **Abstract 工具**：
  - `detect_horizon_mismatch`（视域错配检测）
    - 入参：用户使用的解释框架、对象本身的所属领域
    - 出参：两者是否可通约；若不可通约，错配在哪一层
    - 教学价值：这是抓「用旧框架硬套新概念」的通用算子

### C10. 蒯因《经验论的两个教条》(1951)

- **方法论**：分析命题与综合命题没有截然分界；整个知识体系是一张**信念之网**，中心是逻辑，边缘是经验，边缘的冲击可以传导到任何位置。
- **治的失败**：学习者以为某个说法「定义上就对」，其实那只是当前信念之网的一个节点。
- **抽象工具**：`locate_belief_web_node`（信念网节点定位）——判定一个说法处在信念网的哪个位置（可直接被经验反驳 / 需要连带多个假设才可反驳）。

## D 组 · 现象学与身体化理解

### D11. 海德格尔《存在与时间》(1927)

- **方法论**：**上手状态**（ready-to-hand）与**在手状态**（present-at-hand）。工具用着顺手时是透明的，坏掉时才成为被审视的对象。真正的理解是「会用」，不是「能描述」。
- **治的失败**：所有知识都被当作「在手对象」来考问，导致能做对的题，一旦被问「为什么」就傻了。
- **抽象工具**：
  - `switch_to_present_at_hand`（上手转在手）
    - 治的失败：学习者「会用但说不出」。这个工具主动让他把透明的工具变成审视对象
    - 出参：该追问的是「你刚才用了什么」而不是「请解释这个定理」
  - `restore_ready_to_hand`（在手复原上手）
    - 治的失败：过度审视导致「什么都说不清，反而不会做了」（体育、语言、编程都常见）

### D12. 维特根斯坦「不要想，而要看」

- **方法论**：哲学病来自语言放假。治疗方法是对**具体用例**的细致描述，而不是构造更多理论。
- **抽象工具**：`demand_concrete_case`（向具体用例下压）——当用户开始构造抽象理论自洽时，逼他给一个具体例子，看理论在该例上是否真的跑得通。

## E 组 · 实践与失败

### E13. 波普尔「通过错误学习」+ Bacon's idola

- **方法论**：知识增长靠有胆量的猜想 + 严厉的检验 + 从失败中学习。
- **抽象工具**：`design_killing_test`（设计致命检验）——针对用户当前的理论，设计一个最小的、最能一击必杀的具体检验。

### E14. 杜威《我们如何思维》(1910)

- **方法论**：反思性思维五步——困难感 → 定位困难 → 提出假设 → 推演后果 → 检验。第一步是**混乱感的察觉**。
- **治的失败**：学习者连「我哪里不懂」都说不出来，于是无法求助。
- **抽象工具**：`localize_confusion`（困惑定位）——把「我不懂」转成「我在第几步、哪个具体动作上不确定」。
