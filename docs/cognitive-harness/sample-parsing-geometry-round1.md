## 一、题目（人肉判定基准）

**题干**：
已知椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{2} = 1$，点 $P(4, 0)$ 在 $x$ 轴上。
过点 $P$ 作直线 $l$ 交椭圆于 $A, B$ 两点。线段 $AB$ 的垂直平分线交 $x$ 轴于点 $M(x_0, 0)$。
求 $x_0$ 的取值范围。

**满分要点（这就是人肉判定标尺）**：

| 编号 | 关键点 | 典型扣分 |
|---|---|---|
| K1 | 必须分 **斜率存在 / 不存在** 两类讨论 | 漏垂线情形，扣 2~3 分 |
| K2 | 斜率存在时，设 $y = k(x-4)$，联立椭圆得二次方程 | —— |
| K3 | 必须有 **$\Delta > 0$** 才能保证两个交点 | 忘验判别式，扣 2 分 |
| K4 | 用韦达定理求中点坐标，而非硬解 $x_1, x_2$ | 硬解算崩，时间不够 |
| K5 | 垂直平分线斜率是 $-1/k$，过中点，令 $y=0$ 得 $x_0 = f(k)$ | —— |
| K6 | 把 $\Delta>0$ 给出的 $k$ 范围**代入** $x_0=f(k)$ 求值域 | 只给 $k$ 范围就收工，扣 2 分 |
| K7 | 垂线情形单独算，得一个孤立点，**并入**最终范围 | 算出后忘了并进去 |

**本题的实际结论**（供后续比对模型判断是否漂移）：
斜率存在时 $x_0 = \dfrac{4k^2+2}{k^2+2}$ 型表达式，$k \ne 0$ 且 $\Delta>0$ 约束下可得
$x_0 \in (0, 4)$ 区间的一部分；斜率不存在时 $x_0 = 4$（端点）。
合并后 $x_0$ 的取值范围需按上述讨论精确给出 —— **具体数值以用户核对为准**，
本文件不锁定答案，只锁定「必须讨论哪几件事」。

## 二、学生（AI 扮演）的开场白

> 老师，这道椭圆题我思路有了，但不确定对不对，你帮我看看。
>
> 我是这么想的：P 在 x 轴上，不在椭圆上，所以我设直线 $y = k(x-4)$，跟椭圆联立，
> 得到关于 $x$ 的二次方程。然后用韦达定理拿到 $x_1+x_2$，就能算中点坐标了。
> 中点有了、斜率也有了，垂直平分线就写得出来，让它跟 $y=0$ 联立，就能解出 $x_0$。
>
> 最后 $x_0$ 是关于 $k$ 的式子，$k$ 的范围我用 $\Delta > 0$ 解出来，代进去就是答案。
>
> 这样想对吗？

**这段开场白里，故意埋了 3 个可被攻击的点**（用于测试骨架是否真的触发）：

| 埋点 | 对应骨架 | 期望 AI 抓住的内容 |
|---|---|---|
| 「所以我设 $y=k(x-4)$」——直接把斜率存在当成默认 | `F1.degeneracy` | 垂线情形（K1）完全没提 |
| 「用韦达定理拿到 $x_1+x_2$」——说了用什么，没说凭什么能用 | `F2.felicity` / `F2.warrant` | 韦达定理的恰当性条件（$\Delta>0$、二次项系数非零）未验证（K3） |
| 「代进去就是答案」——从 $k$ 的范围到 $x_0$ 的范围，中间跳了一大步 | `F2.warrant` + `F5.step` | K6 的代换与求值域没有展开 |

## 五、本样本的用法

1. 把第二节的学生开场白 + 第三节老师的话，作为两轮对话喂进系统。
2. 记录第四节的观察。
3. 若模型没抓住 K1/K3/K6 中任何一个 → 回到 `v1-definition.md` 第五节「撞墙时怎么改」的表格对症下药。
4. **禁止**：为了让模型抓住 K1，往提示词里加一句「记得讨论斜率不存在」。
   那是胶带。正确的改法是检查 `F1.degeneracy` 的 trigger 是否写得太窄。
