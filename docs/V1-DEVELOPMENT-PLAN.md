## 0. 摘要

第一版唯一大方向 = **会话算法**：让用户打开手机上的应用，能完成一套完整的使用。核心三个方向——**正常创建会话、使用交互、基础面板服务**——每个方向下分小分支，垂直模块化开发。拍照识题、陪伴主动观察、复盘、子分支等主题**不是第一版的大方向**，其中可做的作为功能模块挂在三方向之下，其余按 §9 的暂缓/长期路线排队。

## 1. 战略定位与技术路线

- **产品形态**：线上应用，原生安卓（Kotlin + Jetpack Compose）+ 服务器后端，前后端分离开发。
- **模型通道**：DeepSeek 官方 API，经 hub 网关统一路由。
- **PWA 旧版**（旧 main 分支）：安装包与代码保留在远端仓库、不删除；后续版本继续在远端仓库打包新版本，由原生安卓版本**全量覆盖**，不再走套壳封装外部浏览器的 PWA 路线。
- **Harness/hub 定位**：产品地基，承载「产品本身的算法」（渠道接入、模型路由、上下文工程等通用会话工程）；「功能算法」（学习策略、记忆、掌握度、遗忘曲线等领域算法）长在安卓端与后端领域层，不在 Harness 里。
- **完全自定义不做**：用户想怎么用就怎么用的完全自定义会让软件跑偏、稀释「学习存档真实性」这一核心承诺。
- **版本编号约定**：宪章里的 V0~V6 是工程排期的内部编号（V1 单会话闭环已验收收官），产品叙事一律以「三方向」为准。

## 2. 第一版终点画面（验收口径）

> 用户在手机设备上打开软件 → 创建会话 → 可以长时间聊天；聊天过程中能通过上传的数据库/资料**自动进行 RAG**，严丝合缝不跑偏，准确使用用户提供的数据源（必要时 AI 也可自行搜索补充）→ 记忆图谱让用户看到自己的**学习存档点** → 面板里有 AI 创建的学习计划、每日总结、token 消耗 → 锁屏/开机后能收到 **AI 主动推送的消息**。

交互体验基调：不能让用户感觉始终在学习、压力太大；允许适当跑偏、闲聊杂话，正常交流；**AI 意图不能太强，既是引导也是陪伴**。

## 3. 方向一：正常创建会话

**现状（2026-09-22 盘点）**

- 窗口设计面板：已做好。
- 创建会话链路：已跑通（模板创建 → 学习策略 → 窗口上下文）。
- 创建会话面板的完整设计、相关子页面：未做。

**第一版待做**

1. 创建会话面板的完整设计定稿与实现；
2. 创建流程相关子页面补齐；
3. 模板 + 学习策略体系保持领域对象形态（后续新增策略——如「正向辅导」教学式策略——走该体系增量扩展，不动架构）。

## 4. 方向二：使用交互

**已在位**：单会话最小闭环（模板创建 → 学习策略 → 窗口上下文 → 生成 → 回复 → 轮次持久化 → 学习结果 → 重启恢复），宪章 V1 已验收。

**第一版待做**

1. **RAG**：用户上传的数据库/资料自动检索注入对话；优先准确使用用户提供的数据源，不跑偏；必要时 AI 可自行搜索补充数据源。
2. **语音输入**：系统 SpeechRecognizer 语音转文字进输入框；第一版不做语音播报（TTS）。
3. **图片上传**：聊天中可上传图片。
4. **富文本输出**：
   - 代码题 → 代码框 + 语法颜色高亮；
   - 数学题 → 数学公式渲染成真实数学符号文本（LaTeX 级渲染），不允许裸 MD 格式符号直接出给用户；
   - 其余输出保持正常富文本。
5. **闲聊兼容（陪伴属性）**：意图识别（本轮是学习还是闲聊）+ 风格策略 + 写入门禁（闲聊轮次不强塞学习目标、不写学习台账）。陪伴是**基础服务属性**——不是为了陪伴而陪伴，而是在学习过程中有人陪伴、有人引导；**不做独立陪伴模式**。

**学习行为的锚定方式（重要架构结论，2026-09-22 讨论确认）**

学习线路**不是提示词注入**，行为锚定在三层：

- **策略层**：创建会话时选定的模板 + 学习策略是领域对象，存于数据层；
- **记忆层**：四层窗口记忆（V2 已定稿设计）——L0 滑窗（6000 tokens / 60 条 + 递归摘要）、L1 观察、L2 模式、L3 窗口级有效值；规则提取器先行、BYOK 后置；
- **产出层**：学习台账持久化、错误分类记录、掌握度按证据类型加权 EMA 更新（讲解 0.35 / 提取练习 0.55 / 迁移 0.72 / 延迟提取 0.82 / 纠错 0.90）。

推论：任何「模式切换」若只靠提示词完成即为坏架构——长上下文跑偏后无结构兜底。复盘、陪伴等主题的落地必须锚定数据与契约（见 §9）。

## 5. 方向三：基础面板服务

**已在位**：设置页（基本正常，无大问题）；记忆图谱无黑洞版（graph-lite，已并入 Android 分支）。

**第一版待做**

1. **图谱接入真实会话数据**：学习存档点在图谱上可见（依赖后端遗忘曲线函数，见 §9 待输入项）；
2. **学习计划卡片**：AI 为用户创建的学习计划展示；
3. **每日总结**；
4. **token 消耗面板**（与 V2 待定项「token 用量统计埋点」合并实施）；
5. 会话管理相关子页面。

**V2 待定项（随面板/记忆线推进时逐项定）**：token 用量统计埋点、BYOK 交互细节、第 3 层契约、规则提取器 v1 规则清单、分身窗口 system 标记契约落点。

## 6. 系统组件

**第一版做**

- 系统通知接入；
- 心跳设计：AI 账户能主动给用户发消息；
- 锁屏消息：锁屏后/开机后第一条消息可以是 AI 的推送。

**暂不做**

- 桌面系统小组件卡片（形态还没想好，归其他功能，后续单独定）。

## 7. 社区（第一版切法）

**定位**：所有用户分享自己的 **AI 人格/窗口设计**（做会话的窗口的完整设计），**不涉及真实聊天记录**，其余设计均可分享。

**五层拆解与归属**

| 层 | 内容 | 规模 | 归属 |
| --- | --- | --- | --- |
| L1 | 分享链接 + 技能卡：设计导成 JSON 嵌入链接（本地自动产出、零后端），点开渲染成技能卡/人物卡式卡片，可一键导入 | 小-中（纯端上） | **v1** |
| L2 | 社区 feed：发布/列表/下滑刷新/每日热度刷新（热度=点赞+浏览+时间衰减简单公式） | 中（后端第一套 UGC 服务） | **v1** |
| L3 | 审核（见 §8） | 小-中 | **v1 与上架里程碑绑定** |
| L4 | 首页：官方公告/更新内容/活动卡片/公益广告位（第一版手动配置，挑战活动手动搓一版） | 小 | **v1** |
| L5 | 推荐算法（抖音式）、活动大赛体系（AIGC 创作大赛/公益广告大赛、作品上传与展示、作品作广告素材）、贴吧式子社区 | 大 | v1.1 及以后 |

**工程硬要求**：分享链接的 JSON schema **必须带版本号**——链接发出不可回收，老链接在新版本上必须能安全降级解析。

**附件（v1.1）**：分享链接本身不含数据文档；PDF/Word 等资料单独上传走服务器存储，单文件 ≤20~30MB，配额限制；图片走文本嵌入框展示。

**工程量参照**：v1 切法 ≈「创建会话」方向体量；社区完整版在此基础上再翻 2~3 倍。

## 8. 审核与上架策略（2026-09-22 拍板）

**审核与上架里程碑绑定**：

- 当前分发渠道 = 官网自建源 APK + GitHub Releases（侧载），**未上架应用市场**；
- **不上架应用市场，API 审核可暂缓**；举报入口 + 后台删除作为低成本管理手段保留；
- 一旦决定上架（应用市场或小程序），API 初审必须在上线前接通——方案已定型，即接即用；
- 是否上架、是否做微信小程序，**依据真实流量反馈再决策**。小程序有独立的成本与资质链（类目审核、软件著作权、微信平台内容安全接口），与安卓应用市场上架材料一并列入「上架里程碑检查清单」。

**定型审核方案**（上架时启用）：API 初审（发布时同步审，不过即拒）+ 举报入口（人工处理举报队列）+ 后台可删。

**推荐通道与定价依据**（腾讯云官方文档，2026-09-22 查证）：

- 腾讯云文本内容安全：按量后付费 **25 元/万条**（不满 1 万条按比例折算，日结）；新客 **3000 条免费试用 15 天**；
- 量级估算（假设口径）：每天 50 帖 + 200 评论 = 250 条，月约 7500 条 ≈ **19 元/月**，实际按用量走；
- 图片审核（后续附件需要时）：数据万象 1.5 元/千次，多场景分别计费——勾几个场景收几次费，初期控制场景数即控制成本；
- 来源：https://cloud.tencent.com/document/product/1124/37118 。

**不在 4GB 服务器自部署审核小模型**（2026-09-22 拍板）：生产机（nginx/后端/hub/官网同机）仅剩约 2GB 空闲内存，小模型推理 OOM 风险威胁主服务；升级内存（腾讯云 CVM 支持变配，需重启）至 8GB 后可再议。

## 9. 暂缓与长期路线

**暂缓（第一版不做）**

- **子分支会话**：设计难度大，价值需要长期体验才能发掘，短期体验先做扎实；群聊模式将来沿子分支基建反向长出（目前尚无多会话拉群方式）。
- **复盘模块**：数据驱动工作流（需要学习台账读模型 + 遗忘曲线 + 复习编排 + 调度），提示词版复盘只会「演」复盘、编内容，毁信任；掌握度评分已为其预留「延迟提取」证据位，等记忆拓扑与遗忘曲线就绪后做正规模块。
- **陪伴主动观察**、**桌面小组件**、**微信小程序**：功能模块/独立决策，见 §8。

**长期候选（排队顺序：正向辅导 → 群聊 → 小六子）**

- **正向辅导**：真正的教学式辅导策略，走现有模板/学习策略体系做增量，成本低；
- **群聊模式**：依赖子分支/多会话基建，排在子分支线之后；
- **小六子 · 全能管家**：窗口算法成熟后启动——所有窗口的综合完全体，管理所有不同窗口的记忆，是软件的大管家。

**待后端输入（阻塞项）**

- 真实遗忘曲线函数数值（替换图谱 protectionSeconds=90f / forgettingFullSeconds=240f 等占位）；
- AI 输出问题定义。

**工程治理待办（沿用宪章体系）**

- AILY-NEWMP-NEXT-STAGES 的 Task 0~6 串行计划继续作为工程执行序列（Gate 迁移验收 → 行为映射 → V1 统一验收 → 记忆演进 → 子分支 → heartbeat → 投影与前端交接）；
- P3-003 诊断错误记录：已批准待实施；
- P3 窗口回合快照、P6 学习概览掌握度读模型：未批准，随对应方向推进时再议。

## 10. 决策记录（2026-09-22 需求分析讨论）

本节留存关键拍板，便于回溯：

1. **唯一大方向 = 会话算法**，核心三方向（创建会话 / 使用交互 / 基础面板服务），垂直模块化开发；
2. **陪伴 = 基础服务属性**，不是目的、不做独立模式；闲聊兼容作为交互能力并入「使用交互」；
3. **复盘第一版不做**，后续作为数据驱动正规模块；
4. **完全自定义不做**（会让软件跑偏）；
5. **社区 v1 切法**：分享链接卡片 + feed 骨架 + 手动首页；子社区、推荐算法、活动大赛挪后；
6. **审核方案定型**（腾讯云内容安全 API 初审 + 举报 + 后台删除）且**与上架解耦**：不上架可暂缓 API 审核；
7. **陪伴模式位置让位**：群聊模式（沿子分支基建）与正向辅导（沿模板/策略体系）均入长期候选；小六子管家为长期愿景；
8. **桌面小组件暂不做**；系统通知 / 心跳主动消息 / 锁屏消息第一版做；
9. 旧 ROADMAP（2026-05 PWA 草稿）仅存档参考，其 V3~V6 主题如重启只作功能模块。

## 11. 开发顺序定稿（2026-09-23 拍板）

**五步开发顺序**（用户在任务评论中确认）：

1. **方向一+二主体**：创建会话与会话交互闭环（语音/图片直传无门控；记忆层补 L1 观察 / L2 模式 / L3 窗口级有效值；RAG 调优不重建）；
2. **数据读接口补齐 + 面板服务**（学习看板雏形 LearningOverviewCoordinator 已接线，接真数据渲染）；
3. **图谱接真数据**（遗忘曲线函数、AI 输出问题定义到位后按接口投影）；
4. **系统组件**（通知、心跳、锁屏 AI 推送）；
5. **社区 L1**（分享链接 + 技能卡，纯端上）。

**开工起点**：第 1 步（方向一+二主体，用户选定）。

**embedding 渠道拍板（2026-09-23）**：

- 默认**内置硅基流动 BAAI/bge-m3 免费档**做兜底向量渠道；免费档撞限速则升 Pro（0.07 元/百万 token）；阿里云百炼 text-embedding 系列为备选；
- **用户自配渠道永远优先**：EmbeddingModelDiscovery 既定行为为向用户渠道 GET /models 自动发现向量模型，命中即用；
- DeepSeek 官方 API 无 embedding 模型（官方文档 api-docs.deepseek.com 实证：模型列表仅 deepseek-flash / deepseek-v4-pro），用户仅配 DeepSeek 时自动退回关键词检索，RAG 不中断；
- 内置兜底 key **不明文进 APK**，走服务器转发（在第 1 步 RAG 调优项中落地）；
- 不自托管向量模型：4GB 生产服务器内存（余量约 2GB，bge-m3 半精度加载即约 1.1GB+）与无 GPU 的 CPU 推理均不具备，且 RAG 文本本就随对话出设备、自托管无隐私新增收益。

**图片上传不门控（2026-09-23 拍板）**：图片正常上传直发模型（DeepSeek-V4.1-Flash 官方支持图像理解）；模型不具备视觉能力时由其自述，用户自然感知；后续可自研 OCR 文字提取兜底，但上传功能不设前置禁用。
