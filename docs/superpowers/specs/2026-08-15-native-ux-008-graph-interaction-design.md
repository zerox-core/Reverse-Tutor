# NATIVE-UX-008 · 原生图谱交互与审核规范

## 目的与边界

本规范为现有原生 Compose 图谱固定用户交互契约：状态呈现、Canvas 与节点列表的关系、选中与详情、证据出口，以及审核动作的风险分级确认。

图谱继续使用现有原生 Canvas、`KnowledgeGraphUiState`、`GraphLayoutNode` 和已存在的 `onNodeLabelSave` / `onNodeReviewAction` 回调。本任务不修改布局算法、物理参数、`GraphNode` / `GraphEdge`、Repository、Room、协议、LLM、PWA 或应用路由。

## 架构裁决

1. Canvas 是唯一图谱渲染器，但不是唯一操作或阅读入口；节点列表和详情是同等有效的无障碍路径。
2. 状态面板只展示既有状态与真实可执行动作，不把资料或聊天证据缺失伪装为可跳转。
3. 节点审核按风险分级：`归档`与`隐藏`必须二次确认；`通过`、`标为需审核`和`恢复为活跃`直接调用既有回调。
4. 确认弹窗是 presentation 层临时状态，不创建新的持久化审核状态。用户取消时不调用回调；用户确认时只调用一次。

## 图谱状态矩阵

| 状态 | 页面呈现 | 可执行动作 |
|---|---|---|
| 加载中 | 明确正在读取本地图谱，不展示旧数据充当结果 | 等待 |
| 空 | 说明当前会话信息不足，解释如何形成图谱 | 去聊天补充学习证据 |
| 失败 | 说明读取失败不影响聊天或资料 | 重试加载 |
| 就绪 | Canvas、fit/reset、节点选择与节点列表入口 | 平移、缩放、选中、查看证据 |
| 需审核 | 展示有效关系数量与需修复关系数，打开节点列表 | 查看节点、审核节点、查看存在的证据 |
| 大图谱 | 说明图谱规模，默认提供节点列表 | 节点列表、选中节点、Canvas 浏览 |

`Invalid` 和 `Large` 状态均不得将 Canvas 手势作为唯一继续路径。没有聊天或资料 target id 的节点详情不得显示相应动作。

## 交互层级

### Canvas 与控制

- Canvas 保留平移、双指缩放、点按选择以及 fit/reset 控制；控件文字或语义描述可被辅助技术读取，触达范围不小于 48dp。
- 选中节点后，Canvas 不再自动清除选择；用户可通过关闭详情、点击空白处或节点列表选择其他节点来改变选择。
- 节点列表按已有稳定排序展示标签、类型和状态。选择列表项与点按 Canvas 节点必须走同一个 `onSelectedNodeChange(node.id)` 入口。

### 节点详情

详情内容顺序固定为：节点名称和类型、当前状态与关系数量、证据摘要、可用证据动作、编辑与审核动作。

聊天证据和资料证据分别显示；二者同时存在时并列出现。证据摘要不存在时显示“当前没有可跳转的证据。”，不提供空按钮。详情关闭仅清除 UI 选择，不改变节点状态。

## 审核与确认规则

| 动作 | 是否确认 | 确认说明 | 确认后的行为 |
|---|---|---|---|
| 标为需审核 | 否 | 无 | 立即调用 `MarkNeedsReview` 回调 |
| 通过 | 否 | 无 | 立即调用 `Approve` 回调 |
| 恢复为活跃 | 否 | 无 | 立即调用 `Restore` 回调 |
| 归档 | 是 | 明确说明节点会退出活跃学习路径，但数据不会被删除 | 确认后调用 `Archive` 回调 |
| 隐藏 | 是 | 明确说明节点会从默认 Canvas 视图移出，可从未解锁节点入口恢复 | 确认后调用 `Hide` 回调 |

确认弹窗必须展示节点名称、目标动作、影响说明、取消和确认按钮。取消不改变任何状态；确认按钮在点击后不可重复触发，直到弹窗被关闭或外部状态刷新。审核回调失败时保留节点原状态并由既有错误/刷新路径表达结果，不在 UI 层伪造成功状态。

## 证据与返回流

```text
Context Hub / 全局图谱
  -> 选择 Canvas 节点或节点列表项
  -> 节点详情
     -> 查看会话引用 -> 原聊天证据
     -> 查看资料引用 -> 资料库（仅真实 sourceId 时高亮）
     -> 审核动作 -> 必要时确认 -> 更新当前节点状态
  -> 关闭详情 -> 回到原图谱视图
```

图谱不创建第二套返回栈；证据跳转沿用 app shell 的既有 target 传递与消费规则。全局图谱与会话图谱共享动作语义，但会话图谱只表达当前会话范围。

## 无障碍与自适应

- Canvas 之外始终能通过节点列表进入详情；大图谱与需审核图谱默认露出该入口。
- TalkBack 阅读顺序为：图谱状态、控制、Canvas 描述、节点列表、节点详情、证据动作、审核动作、确认弹窗。
- 状态、审核结果与隐藏/归档影响必须有文字，不能只依赖颜色或节点透明度。
- 深色模式和大字号下，详情的动作可换行，不遮挡关闭、证据或确认按钮。

## 验收映射

- `UI-GR-001`：图谱保持原生 Canvas，不引入 WebView。
- `UI-GR-002`：平移、缩放、选中、详情、相关证据、fit/reset 和审核动作具备稳定语义。
- `UI-GR-003`：加载、空、失败、需审核与大图谱状态均有明确状态和下一步。
- `UI-A-001`、`UI-A-002`、`UI-A-004`、`UI-A-008`：48dp 触达、阅读顺序、大字号与非 Canvas 操作路径。

UX-008 只定义和验证图谱表现契约，不更新覆盖登记，不宣称 Phase 5、PWA 退出或替换准备已完成。任何未来算法或数据层改动仍须遵循冻结层审批边界。
