# Reverse Tutor Native 完整交互前端设计

日期：2026-07-11  
任务代号：`NATIVE-FRONTEND-COMPLETE-001`

## 1. 目标

在保留当前原生 Android 视觉主题、品牌色、浅色背景和系统字体的前提下，将现有偏静态的 Figma 页面复刻升级为一套完整、可运行、可扩展的产品前端。

本任务不是单页重构，也不是继续增加静态页面。目标是补齐：

- 全局 App Shell、导航和手势体系
- 首页真实信息架构和会话操作
- 横向多屏工作区
- 多厂商模型连接和快速切换
- 新建会话、会话设置和资料接入
- 聊天附件、并发生成和上下文连续性
- 本周总结、计划和可编排小组件
- 全局搜索
- 导入导出、诊断、Token 统计和应用更新
- 所有加载、空状态、失败、恢复和返回逻辑

## 2. 产品原则

1. 保留当前视觉基调，不重新发明品牌主题。
2. 用真实状态和信息增加完成度，不增加无意义装饰。
3. 首页承担会话工作台职责，副屏承担高密度、低深度的学习概览。
4. 技术配置只在二级页面完整展示，普通浏览页面不暴露底层复杂度。
5. 所有可见按钮必须有真实功能；未开放能力使用明确禁用状态。
6. UI 通过 ViewModel、Repository 和 domain model 访问业务，不直接访问 DAO、Entity、SQL 或 SecretStore。
7. 新需求引起的数据和协议变化必须走正式迁移，不使用 destructive migration。

## 3. 整体方案

采用“重建前端交互骨架，复用现有视觉与业务层”的方案。

保留：

- 当前紫色品牌色和浅灰紫背景
- 当前 Compose 主题和可复用视觉组件
- 已有会话、消息、资料、Memory、图谱、导入导出和密钥存储能力
- Repository 作为 UI 业务入口

重建：

- App Shell 和横向工作区
- 页面状态组织
- 首页会话卡片
- 模型连接体系
- 聊天并发 Run 体系
- 副屏小组件体系
- 全局搜索和计划
- 诊断、Token 和更新界面

## 4. 横向工作区

主界面由四个横向页面组成：

```text
[本周学习副屏]  [会话首页]  [全局图谱]  [社区]
```

默认打开会话首页。

### 4.1 手势方向

- 首页手指向右滑：进入本周学习副屏。
- 首页手指向左滑：进入全局图谱。
- 全局图谱继续向左滑：进入社区。
- 各页面保留独立纵向滚动位置。
- 输入框聚焦、组件拖动和图谱全屏时禁用横向分页。
- 横向分页使用距离和速度阈值，避免纵向滚动误触。

### 4.2 分页指示

- 底部显示四个不可点击的微型白点。
- 非当前点约 `2dp`，当前亮点约 `3dp`，间距约 `4-5dp`。
- 当前点带低强度柔光。
- 首次进入时使用低频动态亮点暗示左右页面。
- 用户第一次成功滑动后，本次使用期间停止主动动画。
- 指示器不获取焦点，不遮挡内容，不成为浏览重心。

### 4.3 首页下拉挑战

- 首页列表在顶部时允许下拉进入挑战活动页。
- 未达到阈值时松手回弹。
- 达到阈值后轻微震动，松手进入挑战页。
- 拖动阶段不提前露出排行榜。
- 首次使用只显示一次“下拉查看挑战”的轻量提示。
- 首页不显示挑战按钮。

### 4.4 图谱

- 横向页内展示全局图谱概览和节点摘要。
- 节点允许点击查看简要信息。
- 点击展开进入独立全屏图谱。
- 全屏状态关闭横向分页，支持拖动、缩放、筛选和节点详情。
- 系统返回退出全屏并回到图谱概览页。

### 4.5 社区

- 社区是横向工作区第四页。
- 当前只显示静态“暂未开放”页面。
- 不展示结构预览、虚假用户、评论、点赞或内容卡片。
- 不提供无效操作按钮。

## 5. 全局菜单与首页顶栏

### 5.1 全局菜单

全局菜单仅保留：

- 导入与导出
- 关于与诊断

菜单只允许点击左上角按钮打开，不支持边缘滑动，避免与横向分页冲突。

### 5.2 首页顶栏

## 6. 首页会话工作台

### 6.1 当前问题

现有首页存在：

- “继续学习”和第一张会话卡重复
- 文本未为右侧按钮预留空间，出现生硬换行
- 所有卡片外观相同，缺少视觉锚点
- 卡片信息过少，页面显得空旷
- 卡片间距、圆角和阴影相对信息容量过大
- 固定三张假数据卡片导致明显半成品感

### 6.2 继续区域

“继续学习”改为紧凑恢复条，不再复制一张完整会话卡：

```text
继续上次学习
宏观经济学基础 · 停在 GDP 与财政政策推演
                                                [继续]
```

规则：

- 内容列和操作列使用稳定布局。
- 标题一行，摘要最多两行。
- 文本不进入按钮区域。
- 显示最近离开时间。
- 随页面滚动离开，不常驻悬浮。

### 6.3 会话卡片

每个会话条目展示：

- 小型主题图标或首字图形
- 会话名称
- 最近学习摘要
- 最后活跃时间
- 当前模型标签
- 资料数量
- 计划、挑战、置顶或生成状态
- 必要时显示细进度线

视觉规则：

- 保留浅色卡片和当前主题。
- 使用低饱和紫、绿、蓝、黄色作为会话识别色。
- 收紧圆角、间距和阴影。
- 边框承担主要层次，避免所有卡片过度悬浮。
- 信息使用稳定行数和省略策略。
- 卡片动态状态不能改变外部尺寸。

列表规则：

- 使用真实会话数据，不硬编码固定卡片。
- 提供“全部 / 置顶”筛选。
- 显示会话总数。
- 使用惰性列表。
- 无会话时展示真实空状态。

### 6.4 会话操作

长按会话卡片显示：

- 重命名
- 置顶或取消置顶
- 快速切换模型
- 导出当前会话
- 删除会话

不提供归档。删除必须二次确认。

## 7. 本周学习副屏

副屏是高密度、低深度的全局学习概览，不是系统控制台。

### 7.1 默认小组件

- 本周学习概览
- 今日计划
- 最近学习动态
- 跨会话学习总结
- 当前挑战
- Token 使用摘要
- 当前模型与快速切换

### 7.2 本周概览

本地实时统计：

- 学习天数
- 活跃会话数
- 完成任务数
- 学习时长
- Token 使用量

模型生成：

- 本周主要主题
- 跨会话薄弱点
- 尚未完成的问题
- 下一步学习建议

模型不可用时，本地统计仍可展示。模型总结按周期缓存，不在每次进入时重复生成。

### 7.3 学习计划

任务来源：

- 用户手动创建
- 会话或挑战自动产生
- 模型建议

模型建议先进入待确认状态，用户确认后才成为正式计划。

计划支持：

- 完成
- 延期
- 修改时间
- 关联会话
- 删除

### 7.4 下钻

- 本周总结进入独立周报页。
- 今日计划进入完整计划页。
- 最近学习动态进入对应会话。
- 薄弱点进入对应节点。
- 模型组件打开紧凑快速切换 Sheet。

### 7.5 小组件编排

- 长按进入编辑模式。
- 拖动调整顺序。
- 允许隐藏组件。
- 通过“添加组件”面板恢复。
- 首版不支持自由缩放。
- 组件只提供紧凑和通栏两种固定规格。
- 排列、隐藏和滚动位置持久保存。
- 编辑时不触发组件原本的点击行为。

## 8. 模型连接与模型项

模型系统拆分为：

```text
ProviderConnection
├─ 厂商
├─ 接口协议
├─ Base URL
└─ API Key secretRef

ModelBinding
├─ connectionId
├─ 模型名称
├─ 能力状态
├─ 最近调用状态
└─ 默认状态
```

同一个连接可以关联多个模型，API Key 只保存一次。

- 新增连接
- 编辑、删除和设为默认
- 获取模型列表

### 8.3 连接配置页

- 配置名称

- 接口协议
- Base URL
- API Key
- 获取模型列表

- 测试连接

### 8.4 能力展示

模型卡片显示紧凑能力摘要，例如：

```text
文本 ✓  图片 ×  流式 ✓  工具 ?
```

完整能力通过底部 Sheet 查看。

聊天中的能力逻辑：

- 明确支持：正常调用。
- 明确不支持：提示并提供切换模型。
- 未记录能力：直接尝试，不增加额外确认。
- 调用返回不支持：保留用户输入和附件，更新模型状态。

### 8.5 状态

- API Key 无效
- 模型不存在
- 无模型权限
- 额度不足
- 临时限流
- 服务商异常

测试不是保存或启用的前置条件。模型级错误不能禁用同一连接下的其他模型。

### 8.6 快速切换

- 副屏切换全局默认模型。
- 聊天页切换当前会话模型。
- 新建会话默认继承全局模型，也可指定模型。
- 会话设置允许恢复“跟随全局默认”。
- 已经发出的 Run 继续使用发送时的模型。

### 8.7 外观和交互设置

模型与设置页除模型管理外，仅保留：

- 主题模式
- 头像显示
- 动画强度

## 13. 并发生成与上下文

每条用户消息创建独立 `TurnRun`，回复固定绑定原始问题。

状态：

- waiting
- running
- completed
- failed
- cancelled

每个 Run 可以独立停止和重试。

### 13.1 因果感知并发

独立问题允许并发调用模型。

连续追问等待依赖回复完成，包括：

- “继续”
- “为什么”
- “举个例子”
- 明确引用未完成消息
- 指向上一轮内容的短追问

### 13.2 上下文顺序

- Run 记录 `turnId`、`sequence`、`parentTurnId`、`contextVersion` 和 `modelBindingId`。
- 上下文按用户发送顺序提交，不按模型完成时间排序。
- 独立 Run 使用发送时的上下文快照。
- 后续消息读取已经提交的完整逻辑历史。
- 离开聊天页后任务继续运行。
- 删除会话时取消全部未完成 Run。
- 迟到结果不得写入已删除会话。

### 13.3 失败

- 显示简洁原因。
- 提供重试。
- 保留文本和附件。
- 不增加复杂错误详情页。

建议边界：

- App Shell / Workspace
- Home / Sessions
- Dashboard / Insights
- Models / Settings
- Search
- New Session / Session Settings
- Chat / Turn Runs
- Plans / Weekly Summary

- `WeeklySummary`
- `TokenUsageRecord`

### 16.3 协调器

- `WorkspaceCoordinator`
- `ModelConnectionCoordinator`
- `ConversationRunCoordinator`
- `LearningInsightCoordinator`
- `GlobalSearchRepository`

### 16.4 迁移

- 正式升级 Room schema。
- 提供 Migration 和升级测试。
- 旧 `LlmProfile` 自动迁移为一个连接和一个模型项。
- 旧会话继续使用原模型。
- 导入导出协议新增版本并保持旧版本读取。
- API Key 继续只通过 SecretStore 保存。
- 禁止 destructive migration。

## 17. 状态规范

所有真实操作至少覆盖：

- idle
- loading
- success
- empty
- error
- retry
- disabled with reason

失败必须可恢复。表单、附件和聊天输入不能因失败丢失。

## 18. 验收

### 18.1 核心流程

```text
配置模型
→ 获取模型列表
→ 保存并设为默认
→ 创建会话
→ 添加资料
→ 进入聊天
→ 并发发送消息
→ 后台完成回复
→ 生成计划和周总结
→ 重启应用
→ 恢复状态
```

### 18.2 交互

- 四屏方向正确。
- 分页指示不可点击且不干扰。
- 首页下拉挑战可用。
- 菜单和分页无手势冲突。
- 所有可见按钮有真实作用。
- 所有返回链正确。
- 小组件可排序、隐藏和恢复。
- 搜索可定位真实内容。
- 模型切换作用域正确。
- 并发回复绑定原始问题。
- 社区保持静态禁止访问。

### 18.3 数据

- 旧模型配置迁移后可用。
- API Key 不进入 Room 明文和导出文件。
- 计划、周报、Token 和组件布局重启后保留。
- 删除会话取消未完成任务。
- 迟到回复不写入已删除会话。
- 老版本备份仍可导入。
- 升级不清空用户数据。

### 18.4 异常

- 无模型配置
- Key 错误
- 模型额度不足
- 单模型无权限
- 断网和超时
- 图片能力不支持
- 文件无法解析
- 多个并发任务部分失败
- 更新下载中断
- 存储空间不足
- 应用被系统杀死后恢复

### 18.5 真机

- 360dp 窄屏
- 当前华为约 423dp
- 字体缩放 1.0、1.15 和更大字号
- 导航键和手势导航
- 软键盘
- 深色和浅色主题
- 前后台切换

### 18.6 性能

- 首页、副屏和横向分页保持稳定。
- 输入发送不等待周报、统计或搜索索引。
- 大量消息和会话使用惰性列表。
- 图谱和并发任务不阻塞主线程。
- 不重复生成相同周报。

## 19. 非目标

- 不更换当前视觉主题。
- 不实现语音输入。
- 不实现会话归档。
- 不实现模型 Temperature、Top P 等高级参数。
- 不实现社区结构预览。
- 不伪造未完成的远端社区数据。
- 不为了 UI 简化而删除现有数据、协议或安全能力。
