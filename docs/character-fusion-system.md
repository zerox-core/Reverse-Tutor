# 人物融合系统 · 后续开发方向

> 状态：设计定案（2026-09-17 用户口述整理），待实施。
> 排期：先落地窗口设置页（V1-034），再进行本系统。
> 归属：**全局创建会话流程**，不放会话窗口设置页。

## 一、定位与归属

- 人物融合是**创建会话时**的一个专属页面，属于全局创建流程，不是单个会话内的设置项。
- 会话的窗口设置页只适合做**微调**：在已有的人物面板里调整数值、更换相似词，不适合做大改动（不重建人物）。
- 原组件库中的「配方组合器（RecipePicker，04）」与「骰子（RandomDice，08）」两个组件**合并为一个面板**；之前版本骰子的**抽卡动画要保留**。
- 「预设卡（PresetCard，09）」也归并进全局创建流程：作为融合面板的一部分，提供预设人物配方 + 微调入口。
- 组件分工总定案（2026-09-17 用户拍板）：**全局创建计划** = 04 RecipePicker + 08 RandomDice + 09 PresetCard；**窗口设置页**保留 = 01 CardRadio + 02 SegmentedPills + 03 MoodSlider + 07 TokenField + 10 HoldToConfirm；05 TemplateComposer / 06 ChatField 未定，暂不安排。

## 二、页面内容

创建会话页提供一系列与人物相关的内容分类，供用户挑选关键词：

- 性格底子（如：弱小、强势、温和、杠精……）
- 小怪癖（如：紧张就结巴……）
- 口头禅
- 背景故事
- 年龄
- 经历 / 身份等其它人物信息

用户完成选择后，点击**骰子（融合）**，系统融合出一个**完整的人物形象**（含立绘风格、语气、开场白、行为倾向等整套设定）。

## 三、融合算法（核心：非线性，不是简单组合）

### 3.1 权重体系

- 每个关键词带一个权重，**整数 1 ~ 9 级**（暂定）。
- 默认权重由自动程序分配（用户不感知）；高级选项里可手动改。

### 3.2 非线性变化

- 融合不是把关键词简单拼起来。权重跨过阈值时，词义发生**跃迁（质变）**：
  - 例：性格「弱小」权重非常高 → 跃迁为「自卑」（词面升级为更深层的心理状态）。
- 关键词之间存在**交互**：多个高权重词组合会产生单看任何一个词都没有的新特质。
- **同样的词组，权重不同，融合结果不同**；只有词组和权重**全部相同**时，结果才会完全相似。

### 3.3 动态演化（随会话深入变化）

- 人物形象不是静态的：随着会话推进、双方越来越熟悉，性格表现会发生**有心理学依据的演变**。
  - 例：高权重「弱小」跃迁成的「自卑」角色，在关系熟悉后会**逐渐变得强势**——这不是随机反转，而是补偿机制的表现（见第四节）。

### 3.4 心理学依据（已查证）

- **阿德勒个体心理学：自卑与补偿**。阿德勒认为自卑感是普遍的人格动力，个体会通过「补偿」克服自卑；补偿走向极端即为「过度补偿」，可表现为外在的强势、支配欲——优越情结本质上是自卑情结的延伸（「自卑感越强烈，征服的冲动就越有力」）。这支撑「弱小 →（高权重跃迁）→ 自卑 →（熟悉后补偿）→ 强势」的角色弧线。
- **社会渗透理论（Altman & Taylor, 1973）**。关系发展中，自我表露的广度与深度随亲密度渐进增加，个体在不同关系阶段展现不同的人格侧面。这支撑「随会话熟悉度解锁更深/不同的行为表现」。

### 3.5 确定性

- 融合结果由「词组 + 权重向量」共同决定：相同输入产生相同人物（可复现、可分享配方）；权重微调即产生可感知差异。

## 四、界面与入口

- 高级选项（改权重）**入口弱化**：不显眼，用一个简单的小图标放在面板一旁即可，不打扰普通用户。
- 融合动作 = 点击骰子，触发**抽卡动画**（沿用之前版本骰子的动画），动画结束揭示融合出的完整人物形象。

## 五、窗口设置页的分工（与全局创建页互补）

- 会话创建后，窗口设置页内的人物面板提供：
  - 数值微调（在既有权重附近小步调整）；
  - 更换相似词（同义/近义替换，不重roll）。
- 不做大改动：不重新融合、不重建人物——要重做请回全局创建会话页。

## 六、会话记忆数据包（workspace 导出）

- 每个会话的记忆区对应一个类似 **workspace 的数据包**（沉淀该会话的记忆、设定、状态等）。
- 提供**下载压缩包（zip）**的方式导出，用户可自行拿走使用。
