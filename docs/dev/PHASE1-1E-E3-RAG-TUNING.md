# 1e-e3 RAG 调优实测：命中率对比记录

> 阶段：1e（大阶段一「方向一+二主体」子阶段）
> 日期：2026-09-23
> 状态：e3 完成（本文），1e 收官
> 配套材料：本目录 `corpus.json`（语料+查询标注）、`e3_rag_tuning.py`（回归脚本，可复跑）、`e3_results.json`（原始结果）

## 一、实测设置

- **模型**：百炼 `qwen3.7-text-embedding`（dashscope compatible-mode，1024 维）。免费额度渠道（2026-09-19 快照余量 ≈100 万 tokens），本次实测总消耗 **35,950 tokens / 30 次调用**，符合「不烧付费额度」铁律。
- **语料**：8 篇仿真真实学科资料（数学×2、物理×2、化学、英语语法、历史、语文，共 15,874 字符，讲义/笔记风格、多段落、含长短段混合），16 条标注查询：13 条有归属资料（5 direct / 5 paraphrase / 1 keyword / 2 跨学科直问），3 条语料外查询（out，期望向量检索返回空）。
- **方法**：回归脚本忠实移植 `SourceChunker`（Kotlin 单测 10 条同款断言全过）与 `SourceContextPortAdapter` 的向量排序（余弦 + 每资料取最优片 + 阈值过滤）和关键词回退（整词 contains 计次）逻辑，对三档 chunk 参数 × 五档阈值扫描评估 hit@1 / hit@3 / 语料外误命中（out_fp）。

## 三、关键发现

1. **向量检索召回极佳**：13 条 gold 查询在三档 chunk 参数、阈值 ≤0.40 下 hit@1 全部命中（top1 分数 0.59~0.88），paraphrase 查询（0.59~0.81）与 direct 查询（0.75~0.88）区分度符合预期。
2. **MinVectorScore=0.30 拦不住语义近邻**：3 条语料外查询在阈值 0.30 下全部误命中——q13「原电池正极负极」打到氧化还原资料 0.5568、q11「完形填空技巧」打到三角函数讲义 0.4784、q10「板块张裂」打到数列 0.3566；即使阈值提到 0.40 仍有 2/3 误命中。gold top1 最低分 0.5902（q15）与 out top1 最高分 0.5568（q13）之间的**分离区间仅 (0.5568, 0.5902)**。
3. **chunk 三档无差异**：300/500/800 三档在所有阈值下指标完全一致；B 档多切 32% 的片（108 vs 82）无任何召回收益，C 档片更少也不掉点。**维持现值 500/50/80，不调整**。
4. **关键词回退对中文查询近乎失效**：现有实现按空格分词后整词 contains，中文自然问句无空格 → 整句当单个词 → contains 必然失败。13 条 gold 仅 3 条（自带空格的）命中，**向量不可用时的检索质量是断崖式下跌**。

## 四、结论与行动

| 项 | 结论 |
|---|---|
| SourceChunker 500/50/80 | **维持不动**（三档实测无差异，更小片只增加存储与调用成本） |
| MinVectorScore=0.30 | **记录为暂定项 1e-t4，不改代码**：在 qwen3.7-text-embedding 分布下 0.30 过低（该模型分数整体偏高），本语料上的合理区间约 0.57~0.58；但阈值与 embedding 模型强绑定，内置兜底渠道定为 BAAI/bge-m3（暂定项 1 未解锁），bge-m3 的分数分布未知，**跨模型迁移阈值无依据**，待内置渠道打通后用同一语料复测再定值 |
| 关键词回退质量 | **记录为暂定项 1e-t5，不改代码**：整句 contains 对无空格中文查询失效，改进方向（字符 bigram / 单字+词组分词计分）涉及检索行为变更，无明确拍板标准，待用户决策 |
| 端上代码 | e3 纯实测，**无代码改动**；降级链（e2）维持现状发布安全 |
