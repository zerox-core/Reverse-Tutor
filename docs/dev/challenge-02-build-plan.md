## 1. 定位

- **一句话**：7 天让游戏宅建立「吃穿住行练」五维健康认知，带走一套能落地的微习惯。
- **模式**：沿用反转家教挑战模式——用户教 AI 学生，教是最好的学；阶段任务驱动，每日会话。
- **受众与难度**：游戏群体为主的泛年轻用户；中间档（不做菜那么简单、不科班那么难），面向大众、求广不求深。
- **展示面**：RAG 检索效果是卖点之一，资料库质量和引用体验要经得起演示。

3. **凯圣王粒度（拍板）**：概念科普层——周期计划四原理（专项性/超负荷/疲劳管理/超量恢复）、呼吸与动作逻辑等「为什么」，**不含具体训练计划**；学生侧不主动甩计划，用户（老师）主动教或追问时才展开讨论。
4. **管线不变**：网页/笔记 → markdown 清洗 → chunker 切片（800字/片）→ documents / doc_chunks / FTS5；KG 抽取概念节点（久坐、超量恢复、褪黑素…）+ 关系边入 kg_nodes / kg_edges（轻量 GraphRAG，不引外部框架）。
5. **采集红线**：凯圣王视频只提炼知识点笔记、不搬字幕原文（版权）；每篇带来源头与 URL 台账。

## 5. 教学评测机制：标准区间打分（拍板新增，核心玩法）

**原理**：反转家教里用户是老师、AI 是学生；challenge-02 的学生人设固定（游戏宅），因此对「这个学生」存在一套有资料支撑的最佳实践区间——标准答案不是死答案，而是一个区间带。

**流程**：
1. 教学中 AI 学生主动发问：「老师，那我该怎么练 / 怎么吃 / 怎么睡呀？」
2. 用户以老师身份给出一份计划或建议。
3. 系统把用户的计划对照 rubric.yaml 的「标准区间」逐维度核对打分，给出反馈：哪些落在最佳区间、哪些偏离、哪些踩了红线。
4. **D7 综合验收 = 阶段问答表现 + 计划核对评测的汇总成绩单。不设打卡**（拍板：碎片化时间学习、完全自由）。

**rubric.yaml 维度草案**（从资料库蒸馏，每维度给：最佳区间 / 可接受区间 / 红线 / 依据来源）：
- **睡眠**：最佳 23:00 前入睡、7-8h；红线 = 长期凌晨 2 点后 + 不足 6h（src-07、src-09）。
- **饮食**：对照膳食八准则（食物多样、蔬果奶豆、少盐少油控糖限酒、规律进餐足量饮水）（src-06、src-04）。
- **运动**：每周 3-5 次中等强度有氧（30min 起）+ 2-3 次力量；计划科学性用凯圣王四原理做概念核对点（src-01、src-10）。
- **久坐中断**：每 30min-1h 起身活动 10-15min（src-01、src-08）。
- **场景针对性**：计划必须适配游戏宅现实（碎片时间、居家、零器械起步）；泛泛的健身房年卡式计划降分。

**打分实现**：LLM 按 rubric 结构化评分（json mode，复用现有 chat_json 重试链），输出分数 + 各维度点评进会话；rubric.yaml 随活动包版本化，评测提示词放 session-template 的 D7 注入块。
